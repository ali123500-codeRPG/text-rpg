| IPP-221 | Refund when an All-X perk reuses a skill's milestone perk | 1, 3 | Parked | Moved from D-221. Raised by Ali (12/11/2026), no build now: an All-X perk (tree passive or skill part) might one day be the same perk as a skill's milestone perk. If so, a perk point spent on that milestone perk is refunded. The use case is a perk that unlocks an ability, for example parrying ranged projectiles: a skill's milestone perk and a tree's All-X could both grant it. One perk with several ways in already exists: Every Sense One is the All-150 part of both Eyesight and Earshot (D-197), granted once by whichever comes first; both ways are free, so nothing is refunded there. Today no All-X perk reuses a ladder perk. grantAllSteps skips a perk the actor already owns, so the spent point would stay spent, and canTake refuses a ladder perk already granted by an All-X. Options to settle when it is built: (a) when the refund applies: only when the All-X grant arrives after the point was spent (recommended), or also block taking it once the All-X is near; (b) what is refunded: the one perk point (recommended), plus any milestone gating it counted toward (a ladder perk counts toward 60/100/140 gating; the refunded perk should still count, since it is still owned); (c) the owned row: switch its source from 'level' to 'mastery' so undo and the refund cannot repeat (recommended); (d) the player is told with a log line and a screen note. |

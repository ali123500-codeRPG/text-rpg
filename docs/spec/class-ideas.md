## Class ideas

Parked ideas about classes: a class, its unlock, its skills, perks or capstone, or a skill parked for a class to come.
They wait here for a classes thread. Each has a fixed ID (CI-n), never renumbered or reused. A row moved from the
"Deferred items" table keeps its number (D-157 became CI-157; the D-n row in the archive points here); a new one is the
number of its own closed GitHub issue, as a D-n is (`docs/instructions.md` section 2). Finished rows move to
`deferred-items-archive.md`.

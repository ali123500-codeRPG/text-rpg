[Threadbound items](part-5-gear/threadbound-items-d-218.md)): new items, how they grow, how they are found, lost or
traded. They wait here for a Threadbound thread. Each has a fixed ID (TI-n), never renumbered or reused. A row moved
from the "Deferred items" table keeps its number (D-218 became TI-218; the D-n row in the archive points here); a new
one is the number of its own closed GitHub issue, as a D-n is (`docs/instructions.md` section 2). Finished rows move
to `deferred-items-archive.md`.

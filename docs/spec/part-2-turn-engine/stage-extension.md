### Stage extension

- **Background call.** After a turn is saved, if the player's zone links to a frontier that has no held extension, code starts a background Agent World builder call for that frontier (WB1). It gets no tier and no story: it builds the ground beyond the frontier, honouring the frontier's brief (target.brief) when the Weaver gave one, with the same stage plan contract. Without a World builder wired (tests), the Weaver call builds it under the same world rules.
- **Held, not saved \[Proposed\].** The result is held in memory, keyed by frontier, for the rest of the scenario; it is not saved.
- **Crossing.** In the turn the player moves into that frontier, scenario setup steps 4–7 run on the held plan in that turn's setup slot, after resolveTurn and before the save. There is no new event roll and no grade check: frontier ground is world, not story. If the call is not back yet, the turn waits for it.
- **Failure.** A failed background extension is not retried; the fallback stage applies when the player crosses that frontier.
- **NPCs at frontiers** (NW3 A, NW8). An NPC whose move reaches an unbuilt frontier waits at its edge with its move spent (frontier_wait). If the player crosses that frontier the same turn, the NPC follows them through into the new zone, after them, and stands at the free spot nearest them (GSM-51). Otherwise its wait starts the same background World builder build the player's frontiers get (target.ahead set, planned for the edge zone's place), at most NPC_BUILDS_PER_TURN (1) a turn and none for a frontier already held; a frontier to a saved zone just loads. When the build is back it is applied before the next turn without moving the player, anyone heading for the frontier now heads for the zone beyond, and the NPC steps in on its next move. If the player reaches that frontier first, the held build is theirs to cross into. Built is not seen: the Map shows the new ground only once the player sees it (S6), which is also how a secret area behind a hidden frontier can exist. In free roam an NPC's build is an extension, never a scenario of its own.
- **Built ground stays live** (WI8 a, Ali 17/11/2026, replacing saved zones and their re-entry). The stage keeps no list of zones: every built zone in the world is live for every system (paths, sound, heading somewhere, healing, chases, scenario endings, plans), ground built in an earlier story as much as this one's, so a new character in an old world finds all of it. A frontier marks only unbuilt ground; a way into built ground is a plain way (a save's old re-entry marks become plain ways on load). Only what the planners and NPC agents are shown is bounded (WeaverView, the NPC map). Nothing is trimmed (D-225 settled).

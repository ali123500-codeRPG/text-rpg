# History: classes, learning from use and Starts

Kind: context. What was asked, what was decided and which PR built it, oldest first. The rules are in the spec
(Part 1 sections 5 and 6, "Player creation" in Part 4); the classes and Starts are rows in `src/library/data.ts`.
How one class unlocks the next is in `class-unlocks.md`.

- **Starting classes and class perks (09-10/11/2026).** Swordsman, the late bloomer "Unwritten Legend", perks
  by class level and class unlocks (#155); Sword-dancer, which mirrors Swordsman (#175); a top level by class
  tier, XP that banks at the top level, Commoner as the plain default and A Nobody (#180, #182, #197); named
  tiers (#185, #266). Every gear class has two starter pieces, one for each of two low requirement steps, and
  none above them (#261). The Swordsman's tree holds only Riposte (#270).
- **Learning from use (09/11/2026).** A trial showed the Unwritten Legend growing only Endurance. Answers: a
  skill that is not on the sheet learns from use; a contest that ends level teaches both sides; no wider
  learning window (#167, #168, #173). The owner's view: raw skill mostly unlocks perks, and perks move the odds
  most, so weak scaling of odds with raw skill is intended and is not a problem to flag.
- **Unwritten Legend capstones (09/11/2026; L1, L2; D-121).** One default capstone and two alternates with
  their own conditions; the default stays inactive until the player keeps it or picks an alternate (#184,
  #194, #196).
- **Starts (14/11/2026; DX1, CC1-CC9).** Starting classes became Starts, so that a start need not be a class
  and creation can grow; the blessed start begins with a god's blessing (#776, #797). Every Start gets the same
  creation points (#829), and no blessing tier is shown on the creation screen. Commoner is open from the start
  (#809). A new character opens on a random identity (#789). Human and Elf are playable; Slime and Dragon were
  made playable and removed again (#803, #853). The A Nobody and Swordsman starts were retired; the classes
  stay (#800, #829). Parked: blessings and gods (D-311).
- **Class tree (14/11/2026; CT1-CT4).** The class picker became a tree, the only place to change class (#794).
- **A Somebody (16/11/2026; CB1-CB7).** The class between A Nobody and Unwritten Legend (#922). Its capstone
  is parked (ICI-360).
- **The Legend's own level 1 perk (16/11/2026; UL1, UL2).** Any Road Will Do; Quick Study is A Nobody's alone
  (#1006).
- **Reincarnator Start (16/11/2026; D-355, parked).** A hero of this world who lived, died and was reborn. It
  is not the outsider from another world (D-347), and the two stay apart (#910): an idea is folded into a
  nearby item only when its core is the same, not because the genre is alike.

# BG-1745

**What was wrong:** On the creation screen's Personality panel, in two columns, a left-column row's right end label
("honest", "disciplined") ran into the right column's trait names (Pride, Curiosity).

**Root cause:** `src/ui/styles.css` sized an axis row's tracks in `rem` (name `11rem`, end labels `7.5rem` each) while
the column minimum (`.pe-axes`, `minmax(520px, 1fr)`) and all the text in the row are in `px`. With a browser default
font size above 16px (Chrome's "Large" is 20px), the rem tracks grew past the 520px column; the ends track is
`minmax(0, 1fr)`, so the row spilled into the next column instead of widening it. Rendered before the fix at 1280px
with a 20px root: the right end label ended at 700px against a column edge of 654px, 14px of page overflow.

**What was done:** the row's tracks are in px like their 13px text (name `176px`, end labels `120px`, the same sizes at
16px), so a row needs about 504px whatever the browser's font size, inside the 520px column. Rendered at 1024 to 1920px
with a 16, 20 and 24px root: every row ends inside its column, 0px overflow. No other layout in `src/ui` uses `rem`.

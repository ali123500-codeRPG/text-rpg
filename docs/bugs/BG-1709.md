# BG-1709

**What was wrong:** `tests/unit/map-land-ui.test.ts` ("whole turn: … on the mill road your pin sits on its line") failed
in CI on `main`, on a spec-only commit, and passed when the same job ran again.

**Root cause:** The same as BG-1699; this is a second report of it. Every failing run was on a commit made before the
BG-1699 fix (#1704) reached `main`: the CI `test` jobs of 6790b25 (#1692), 4ef18e1 (#1698) and 0e24190 (#1693), each
failing at `expect(road.line).toEqual(line.pts)` with 32 points against 40, the BG-1699 signature. The dev page's land
(`fakeLand`, `src/ui/fakeGame.ts`) was cached once per module load, and test files share one load per worker
(`vitest.shared.config.ts`), so when `tests/unit/map.test.ts` ran first in the same worker this test got the 10 km region
instead of the 5 km one it sets, and its mill road line then started inside Millbrook's square. Which file a worker runs
first changes from run to run, hence the pass on a re-run.

**Why it caused the symptom:** On the 10 km region the road's title line is the land road's line less its stretch inside
the square (BG-1679), which the old assertion did not allow for; the 5 km region happened not to show it.

**What was done:** Nothing more in code: #1704 had already made `fakeLand` draw again at a new region size and made the
test check the BG-1679 rule. The test is not weakened.

**Also affected:** The test's other inputs are steady: the fake game's turn is deterministic (no `Math.random` or clock
reads on that path; the 600 ms pause only waits), the land is drawn from a fixed seed, and the shared run resets CONFIG
after each file (`tests/harness/turnCheckSetup.ts`). None found.

**Verified:** Since #1704 merged, every CI run on any branch passed (24 runs at the time of writing). The test alone,
8 runs in a row, passed. In the shared module load with `--maxWorkers=1 --sequence.shuffle`, the land and map files
together (`map`, `map-plan`, `map-floor-plan`, `backdrops`, `land`, `s315`, `s316`, `s387`, `map-land-ui`) passed on
seeds 1 to 12; seed 3 is the order that failed before BG-1699.

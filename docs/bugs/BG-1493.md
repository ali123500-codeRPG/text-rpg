# BG-1493

**What was wrong:** The hero was told to pull the essence out of someone who had surrendered, a step away in the same room. The hero did not move, and the extraction came to nothing as out of reach, 0 m short.

**Root cause:** The walk before an action on someone is planned by `reachOf` (`src/engine/resolve.ts`). For every grip action except a grab, tending with an item and a filch, it added the target's own grip reach, as for a hand-over, where both people reach out. An extraction (`cantExtract`, `src/engine/extract.ts`) and tending wounds (`doHeal`) check only the actor's own grip reach. So the walk thought the hero was already close enough, at up to both reaches (1.25 m for two people), and stood still, while the action needed 0.625 m. The "0 m short" came from the same wrong reach, since the shortfall is measured against `reachOf`.

**What was done:** `reachOf` now adds the target's reach only for the actions that pass a thing between two hands: give, take, buy, sell and repair (`HANDED`). Every other action on someone (an extraction, tending, a grab, a filch, using an item on them) walks to the actor's own reach, the same reach the action checks. Covered by the new `s415-extract-closes-in`, which fails before the change. `s303-essence-extraction` still passes.
